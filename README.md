# 💅 EVE Nail Design

> Solução web desenvolvida para uma profissional real da área de Nail Design, com o objetivo de fortalecer sua presença digital, apresentar seus serviços e ampliar o alcance do negócio.

## 📌 Sobre o projeto

O **EVE Nail Design** é um projeto de desenvolvimento web criado para uma cliente real do segmento de Nail Design.

A proposta é desenvolver uma página moderna, responsiva e intuitiva que permita à cliente apresentar seu trabalho, seus serviços e suas informações de contato de forma mais profissional, facilitando o acesso de novos clientes ao negócio.

O projeto está sendo desenvolvido utilizando o conceito de **SPA (Single Page Application)**, proporcionando uma navegação mais fluida entre as diferentes seções da página.

---

## 🎯 Objetivos

* Criar uma presença digital para o negócio;
* Apresentar os serviços de forma clara e organizada;
* Facilitar o contato entre clientes e a profissional;
* Melhorar a experiência de navegação;
* Tornar o negócio mais acessível para novos clientes;
* Aplicar conhecimentos de desenvolvimento Front-End em um projeto real.

---

## 🔎 Processo de desenvolvimento

Antes de iniciar a implementação, o projeto passou por etapas de planejamento e prototipação.

### 1. Estudo da cliente

Foi realizado um levantamento das necessidades do negócio, buscando compreender:

* Perfil da cliente;
* Serviços oferecidos;
* Público-alvo;
* Necessidades do negócio;
* Informações importantes para os usuários;
* Objetivos da solução web.

### 2. Wireframe

Após o levantamento inicial, foi desenvolvido o **wireframe**, permitindo definir a estrutura da página e a organização dos conteúdos antes da implementação.

Essa etapa ajudou a visualizar a hierarquia das informações e o fluxo de navegação.

### 3. Prototipação no Figma

Com a estrutura definida, foi criado o projeto visual no **Figma**, trabalhando aspectos como:

* Layout;
* Hierarquia visual;
* Tipografia;
* Cores;
* Componentes;
* Navegação;
* Experiência do usuário.

### 4. Desenvolvimento

Após o planejamento e a prototipação, iniciou-se a implementação da solução utilizando **HTML, CSS e JavaScript**.
